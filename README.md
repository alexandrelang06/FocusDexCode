# FocusDex

Code source de l’application iOS FocusDex, avec son widget et ses Live Activities.

## Ouvrir le projet

Ouvrir `FocusDex.xcodeproj` dans Xcode, sélectionner le schéma `FocusDex`, puis choisir un simulateur ou un appareil sous iOS 17 ou version ultérieure. Pour un appareil physique, configurer la signature avec son équipe Apple Developer.

## Contenu

- `FocusDex/` : application SwiftUI, ressources et illustrations.
- `FocusDexWidget/` : widget et Live Activities.
- `Shared/` : attributs partagés avec l’extension.
- `FocusDex.storekit` : configuration StoreKit locale.
- `PRD-FocusDex.md` : spécification du produit.
- `docs/privacy.html` : politique de confidentialité de FocusDex.
